# Plugins

This document describes the Plugin system, means of extending Forecast-in-a-Box with custom products and data sources.
It is intended for advanced users and operators, and describes how to configure or troubleshoot a plugin installation.

There is also a [developer-focused document](../developer/guidelines/plugins.md) about plugins, which describes what a python package must satisfy to be a well-behaved plugin, and how to setup a local development environment.
